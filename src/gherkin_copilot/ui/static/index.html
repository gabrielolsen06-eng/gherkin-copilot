gherkin-copilot

Write tests faster by reusing the steps you already have

A project is one test suite: a folder of step definitions (the Python code behind each line of Gherkin) and a folder of .feature files. Add one to see every step it already knows.

You can add as many projects as you like and switch between them at the top.

Build a scenario

Snap together steps this project already has. Anything that doesn't exist yet turns red.

Editing . Saving replaces it in the file.

Drag a step into your scenario, or click +.
